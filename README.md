中野年章の個人サイトです。GitHub Pages で公開しています。

公開URL: https://toshiakinakano1965.github.io/

## ページ構成

| パス | ページ | 内容 |
|---|---|---|
| `/`（index.html） | 自己紹介 | 「理想の音は、地平線みたいなものだ。」サックス、ヨット、好きなもの、家族、仕事 |
| `/career.html` | 仕事と講演 | 「好奇心の地図」講演テーマ、講演・登壇実績、キャリア、ご依頼窓口（LinkedIn） |
| `/tenor/` | テナーのセットアップ | Eastman ETS852NL、Guardala MB II、Silverstein Gen 5 |
| `/cars/` | 愛車遍歴 | 「九台のクルマと、四十三年の道。」1983年〜現在の9台 |
| `/morning-dashboard/` | 朝のダッシュボード | Google API の公開審査用の説明ページとプライバシーポリシー（サイト内からはリンクしていません） |
| `/trip2026.html`、`/ryotaro.html` | — | 旧URLの転送用ファイル |

## ファイルの置き場所

- ルート直下の画像（yacht.jpg、band.jpg、talk-booth.jpg など）: 自己紹介ページと仕事と講演ページで使用
- `tenor/img/`: テナーのページの画像
- `cars/`: 愛車遍歴のページと画像
- `.nojekyll`: Jekyll の処理を無効にして、HTML をそのまま公開するためのファイル

## 運用メモ

- 各ページは1ファイルで完結する HTML（CSS・JavaScript を含む）です。
- 公開する写真は、ナンバープレートのぼかし、写り込んだ人物の切り抜き、位置情報などのメタデータ削除を済ませてからアップロードします。
- 講演・登壇の一覧は `career.html` 末尾の `TALKS` 配列に、新しいものを上に追加します。
- 文章の一人称は「僕」で統一しています。
