プライバシーポリシー

朝のダッシュボード（個人用のアプリ）／最終更新: 2026年11月7日

1. 利用者

このアプリは、作った本人だけが使います。ほかの方の情報を扱うことはありません。

2. Google から受け取る情報

  • Google カレンダーの予定（件名・日時・場所）。読み取りだけを許可しています
  • Google ToDo リストの項目（件名・期限・メモ・リスト名）と、完了・未完了の状態

3. 情報の使い方

  • 受け取った情報は、本人のパソコンの画面に表示するためだけに使います
  • アプリが Google に書き込むのは、本人が画面で押したときの ToDo の「完了」と「未完了に戻す」だけです
  • 本人が画面の「アドバイス」ボタンを押したときだけ、今日と明日の予定の件名・時刻・場所と、期限の近い ToDo の件名・期限を、文章を作るために Anthropic 社の Claude API に送ります。体の状態に関わる予定や ToDo の件名は伏せて送ります。ToDo のメモとリスト名は送りません
  • 情報を売ったり、広告に使ったり、ほかの人に渡したりはしません

4. 保存

Google との連携に使う鍵は、本人のパソコンの中に、本人だけが読める形で保存します。予定や ToDo の中身は保存せず、画面を開くたびに Google から読み取ります。

5. Google API の利用について

このアプリが Google API から受け取った情報の使い方と、ほかのアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのアプリへの許可を取り消せます。
